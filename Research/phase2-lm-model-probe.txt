[F] Interpretation
- Across available language bundles, fst.dat is generally unweighted and acyclic; pt/en/fr/sv all report weighted=n.
- This suggests fst.dat is likely a deterministic transduction/index component, not the sole probabilistic LM carrier.
- Sidecars (sp.dat, model.dat, montreal*.dat, unilm.bundle, params.dat) indicate subword + neural LM components in .lm bundles.
- Runtime APIs expose prediction/probability and training/adaptation calls (ConditionalProbability, EnumeratePredictions, MRLModelTrainBatch).
- Working hypothesis: Apple .lm pipeline is hybrid (tokenization/neural scoring + FST mapping), so replacing only fst.dat cannot reproduce Apple behavior.
